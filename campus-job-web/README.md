# 校招岗位筛选 · 网页端

网页端复用桌面端的 Vue 页面、业务组件和 `/api` 接口，独立使用 Vite 构建。
包含工作台、岗位库、与我匹配、关注岗位/投递状态、求职计划、待办日历、简历管理、登录/会员/兑换码。
网申公告与投递地址在浏览器新页签打开；普通网页无法向第三方页面注入简历脚本，自动填写留待单独的 Chrome/Edge 扩展实现。

```bash
cd campus-job-web
npm ci
npm run dev
# http://127.0.0.1:1421/

npm run build
# 产物在 dist/；静态资源路径以域名根路径 `/` 为基准
```

本地开发时 Vite 将 `/api` 转发至 `https://my88ai.com`。生产环境把 `dist/` 发布到 `https://my88ai.com/` 根路径；服务器需将网页未知路径回退至 `index.html`。不要覆盖现有 `/admin/`、`/api/` 和 `/downloads/` 路由。

登录状态是当前浏览器的本地存储，账号与桌面端可使用同一后端数据，但不同设备/应用需分别登录。扩展将来应独立申请用户授权并设计安全的数据交换方式；网页端本身不暴露简历给第三方站点。
