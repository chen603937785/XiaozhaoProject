# 橙子校招 · 微信小程序

使用微信开发者工具导入本目录，AppID 保持现有配置。当前版本仅在本地开发，未上传或发布。

## 页面与接口

- 工作台：求职计划选择/新建/目标编辑/状态管理、岗位阶段统计、今日和逾期待办。
- 岗位库：搜索、多条件筛选、省市联动、岗位详情、关注岗位、复制公告和投递链接。
- 关注岗位：按计划/阶段筛选、主状态与细分状态流转、预计开始提醒、调整计划和取消关注。
- 待办日历：月历、日期标记、手动新增待办、关联计划和优先级、完成/恢复/删除待办。
- 我的：手机号密码登录/注册、昵称编辑、会员到期状态、兑换码兑换、后台配置的会员价格和权益。

登录直接使用客户端相同的 `POST /api/auth/password-login` 和 `POST /api/auth/register`。
计划、关注岗位、待办分别复用 `/api/plans`、`/api/job-status` 和 `/api/todos`；账号相同时数据共用。
登录过期只清理本地登录信息，不调用微信静默登录，不自动重放写请求。
旧版本微信登录缓存升级后需要重新登录手机号账号；旧微信账号/旧收藏的数据库记录不会删除或自动合并。

小程序不支持客户端 Tauri 内置浏览器和注入自动填写脚本。外部网申链接使用复制链接，再到浏览器打开；自动填写需客户端使用。

## 验证

在仓库根目录执行 `node scripts/test_miniprogram.cjs` 检查登录接口、token/401、筛选、日历、待办请求及 Tab 资源。
`scripts/generate_miniprogram_icons.cjs` 可重新生成蓝灰双色底部图标。
WXML/WXSS 已通过微信开发者工具自带编译器；仍需在开发者工具/真机验证实际交互和账号数据。
真机访问需在微信后台配置 request 合法域名 `https://my88ai.com`。
