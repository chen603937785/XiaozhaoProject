# 小麦说职位 0.1.9

PC 网页与客户端左上角统一名称，小麦说职位也用于 macOS 应用名称和窗口标题。保留原应用 identifier `com.campus.job`，不变更账号、简历或 WebView 数据目录。Windows 的绝对路径 data_directory 与 disable-gpu 参数保持不变。

简历页与线上最新版共用 16 模块、173 字段定义；移除 RESUME WORKSPACE，标题、辅助说明和新建操作缩为紧凑单行。中间资料和左右导航仍独立滚动，减少固定标题占用。

自动填写使用插件 manifest 中的十个共用模块。客户端单独维护展示层，保留本地规则优先和原生 AI 识别桥接。默认只填空白，覆盖需确认，不自动提交。默认选择网页记录顺序，多条经历不得复用第一条缺失资料。

收起按钮默认右侧居中，名称为小麦填表插件；收起和展开均支持拖动。简历、模块与具体经历使用自定义选择器。进度按扫描后的实际目标字段计数（包括保留、缺失与未匹配），完成或停止后隐藏进度条、展示结果并提示核对。显示进度、候选菜单与结果时自动约束面板位置，避免超出可视区域。

原始图标保存在 `campus-job-desktop/src-tauri/icon-source.png`。`scripts/round_desktop_icon.py` 生成 1024 画布、92 像素边距的圆角图片，使用 Tauri 图标生成器输出桌面图标；不会对上次已经裁切的输出重复缩小。

验证包括插件引擎 48 项回归、客户端面板专项检查、浏览器拖动/选择器/覆盖/进度流程，以及 1380×800 和 1024×640 的简历布局。页面流程使用虚构资料与本地模拟接口，不向招聘网站提交测试简历。实际招聘站点仍需逐站验收。

Mac 构建目标为 universal-apple-darwin，安装包包含 x86_64 和 arm64。未构建 Windows 安装包。本轮不发布小程序、不部署后端服务、不修改数据库。
