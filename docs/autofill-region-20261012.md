# 信达省市区单选控件

共用 Phoenix 适配器修复了父级地区带下一级箭头时被错误拒绝的问题。可见且启用的单选圆圈允许选择省或市；需要更深层时优先点击支持交互的箭头，旧版没有箭头事件的控件点击地区名称。每层等待候选列表变化，兼容复用 DOM 行与异步加载。

支持完整分隔路径、数组路径，以及「浙江省杭州市西湖区」「浙江杭州」这样的连续中文名称；只依据当前分支实际候选名称解析，不搜索、不选第一项、不推测缺失城市。禁用、重名、网站要求更深层时均不提交。仅当组件回显与选中圆圈一致后点击该地区弹层内「确定」，从不点击简历保存或投递。

保留组件原有「包含下级」设置，校验时只在该开关已勾选的情况下识别回显中的相关附加文字。重新打开已选控件并展开到子层后，填写新路径会先返回顶部面包屑。

版本：插件 0.1.9，客户端 0.1.10，客户端填写脚本 1.3.1。插件与客户端引擎生成自相同模块；本轮安装包也包含此前的会员支付二维码界面改动。

验证：插件 49 项自动回归、客户端面板测试、插件弹出页测试通过。使用信达公开原版 Phoenix React 组件的本地浏览器检查省/市/区级选择、连续中文路径、父级重开、选中编码与必选区县拒绝；没有向招聘网站提交虚构简历。

真实信达页面访问需要登录；当前测试浏览器登录后仍跳转或显示加载失败，不能将本地原版控件验收等同于登录后真实账号表单验收。实际表单验证结果将在完成后补充。

Mac 目标保持 universal-apple-darwin，Windows 保持 x86_64-pc-windows-msvc、NSIS。原应用 identifier、WebView 绝对数据目录和 GPU 参数不变。发布脚本采用哈希资源先上传、清单后切换，保留历史脚本便于回滚。
