# PC 与客户端会员兑换二维码

2026-10-12：PC 网页与客户端共用的 AccountVipModal 移除月卡/季卡/年卡价格栏、会员权益介绍和获取兑换码按钮，右侧上方展示独立支付二维码，图片下方固定文字「微信扫码获取兑换码」。保留昵称修改、会员状态、退出登录、兑换码输入和立即兑换。手机网页和小程序未改变。

后台「兑换码管理」新增会员支付二维码上传与预览，客服二维码保留且独立配置。未上传时显示支付二维码待上传，网络或图片加载异常可重试；图片使用 contain 展示，不裁掉二维码内容。

接口：`POST /admin/membership-payment-qr/upload`，multipart 字段 `file`，须管理员认证。接受可解码的 PNG/JPEG，最大 5MB，宽高各 64–4096 像素；按真实图片格式保存扩展名，文件名由服务端 UUID 生成，不使用用户文件名。写入失败不会改变配置，配置保存失败清理本次新文件；不删除原图片。

配置表复用现有键值存储，新增键 `membership_payment_qr_image`，无需修改数据库连接或建表。公开 `GET /api/config` 增加 `membershipPaymentQrImage`，返回 `/downloads/membership_payment_qr_<uuid>.png|jpg`。客户端补全生产域名，PC 使用同源地址。

这是展示管理员上传的收款二维码及已有兑换功能，不会根据微信付款结果自动生成或发放兑换码，不新增支付订单、回调或支付协议。

验证：Java 8 上传专项 3 项测试；后台加载/上传/预览/错误状态测试；浏览器 1380×800 与 1024×640 下弹窗高度、图片展示、隐藏旧内容、兑换、未配置和错误重试流程通过。测试使用模拟图片和兑换接口，未向线上配置写入测试收款码。PC 与客户端前端构建通过，客户端未打包。

线上后端只替换 ConfigService、增加 MembershipQrController 和更新管理后台静态页，部署目录保留旧 JAR。PC 静态发布目录 `/opt/campus-job/web-membership-qr-release.hpXdQW` 保留旧入口；旧哈希资源与 `/autofill/` 完整保留。
