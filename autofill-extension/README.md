# 小麦填写助手 Chrome / Edge 插件 0.1.9

浏览器原生弹出页管理小麦账号、简历版本和关注岗位，网页独立悬浮框负责填写及控件调试。
执行器不调用 AI，不上传网申页面或简历到第三方。

## 安装与更新

要求 Chrome / Edge 111 或更高版本。

1. 打开 chrome://extensions/ 或 edge://extensions/，开启“开发者模式”。
2. 点击“加载已解压的扩展”，选择包含 manifest.json 的插件目录。
3. 若原扩展加载的是其他目录（例如 output/autofill-extension），请移除旧扩展，
   再加载新的版本目录，避免两份插件同时运行；移除后需重新登录小麦账号。
4. 若继续使用同一个源码目录，在扩展管理页点击“重新加载”。
5. 两种更新方式都要刷新网申网页。弹出页底部版本应显示 v0.1.9。
6. 将插件固定到浏览器工具栏，点击图标会在图标下方打开原生弹出页；点击网页空白或再次点图标自动收起，位置由浏览器定位。
7. 点击弹出页的“打开悬浮操作框”显示独立网页悬浮框。拖动顶部可移动，右上角 × 完全关闭；重新打开仍从弹出页进入。关闭弹出页不会中断网页填写。

## 使用

1. 在原生弹出页使用与客户端相同的小麦账号登录，下拉选择当前简历。
   默认选中官网默认版本，也可选择其他版本；仅选中的简历用于填写。密码不保存，登录凭证保存在扩展本机存储。
2. 修改官网简历后点击“刷新简历”；已打开的悬浮框同步新数据。填写期间禁止切换和刷新。
3. 选择“一键填入方式”。初次默认“仅填新增内容”；选择“全部覆盖重填”后保存设置，后续使用该方式。信息缺失提醒可开关。
4. 展开网页所需的简历模块，在悬浮框点击“一键填入”，自动扫描当前可见控件并批量填写。可点击“停止填写”和“复核结果”。
5. “简历 / 关注岗位”Tab 可切换；关注岗位使用相同账号的真实列表，公告或投递入口在新网页打开。
6. 需要调试时展开悬浮框底部的“控件调试”，查看字段名称、模块、记录序号、匹配路径和实际选中值。
7. 对下拉/级联先“展开并记录”，需要单独调试时输入“本次测试值”，再点击“测试填写”。
8. “填写可匹配项”顺序填写简历中有值且唯一匹配的字段。默认保留网页已有值，
   只有勾选“批量允许覆盖已有值”才覆盖。批量使用简历值，不使用单项手工测试值。
9. 可以随时点击“停止填写”。批量结束会复核已完成字段；后续也可以点击“复核结果”，
   检查是否被网页重置。失败会显示具体原因。
10. 最后由用户核对网页内容并自行保存或提交；插件不点击提交、保存或新增经历按钮。

“修改简历”打开官网，请进入简历资料库；会员按钮打开官网，请进入个人中心开通或续费。
客服读取后台配置的微信二维码；帮助提供填写与调试说明。Chrome 内置页、扩展页等禁止注入的页面只可使用原生弹出页。

## 本次能力

- 电信 WinTalent：只读学校/专业选择器展开后使用真正的搜索框，等待异步候选并点击；支持月份/日期日历和相邻文字单选标签。禁止编辑日期和未知只读文本不会强制写入。
- 信达 Beisen Phoenix：将下拉和日期从普通文本中区分，读取真实候选、点击后检查持久选中标签；日期通过年份、月份、日期面板选择。先“展开并记录”再“测试填写”会复用当前字段的面板。
- Phoenix 地区面板逐级展开省、市、区，点击末级 SVG 单选图标并确认本地地区选择器，检查完整路径或实际选中叶子的回显。路径停在仍可展开的上级时不会提交；不输入地址搜索词。
- 信达字段补充个人评价、院系、学习形式、技能模块下的证书/授予单位/获取时间、家庭关系/工作单位。个人信息中的外语和计算机水平只取唯一语言/技能记录，多条时留给用户确认。岗位类别不再误用具体岗位名称。
- 启动即提供完整内置简历字段定义，接口失败时仍可识别字段；先扫描再加载简历也会刷新匹配。
- 修正报告中的字段语义：长备注生源地、户籍、紧急联系方式、学生实践经验、英语证书等级、技能编号、父母关系。是否最高学历使用明确值或唯一最高学历记录计算；有歧义时留空。
- 英语等级使用证书名称，其他语言排除英语；实习不借用正式工作数据，银行系统内亲属声明不借用普通家庭成员。
- AntD 技能/证书只有叶子名称时，逐层展开分类并检查唯一精确或等价叶子，再点击完整路径。复合技能仅当候选中有唯一对应技能时选择；多个可选项交给手动确认，不用 Java 猜 JavaScript。
- 省市路径缺少下一层时提示补齐，支持旧版级联 label 及闭合后的叶子回显。报告增加输入形态、路径层数、候选数量和执行方式，不导出实际值。

- 普通下拉先展开并等待字典和 loading 结束，根据简历值匹配真实选项；优先滚动读取虚拟列表，树形控件先展开分类再选叶子。
- 光大普通字典与地区控件禁止输入简历搜索词；学校允许在首次加载无匹配后调用搜索。
- 批量结果分别统计未匹配、简历空值、保留已有值与填写失败，可导出排查报告。报告不含简历值、登录凭证、密码或 URL 查询参数。
- 扩展中英文别名，覆盖基本信息、教育、实习/工作、项目、技能、语言及求职意向。
- 结合模块识别同名日期和岗位字段；光大按 record_N 对应经历，
  其他重复表单按扫描顺序对应。简历缺少第二条时不会复制第一条。
- 学校搜索等待异步候选项；中文学历/学位/性别的常见同义名称支持匹配。
- 自定义下拉通过点击真实选项完成，检查实际选中状态，搜索词不能算填写成功。
- 单值省市区级联逐层等待下一列并验证完整路径。值应包含完整层级，
  例如 广东省 / 深圳市 / 南山区；只有城市名时不猜省份。
- Ant Design 单日期、月份、年份选择器通过日历面板选择，支持中文日期回显。
- 原生输入、下拉、单选、复选和富文本；React 文本填写按聚焦、输入、变更、失焦执行。
- 确认控件仍属于扫描时的字段；遇到页面换控件、人工修改、多个同名候选时停止该项。

## 验证和限制

插件回归覆盖异步字典/学校搜索、加载前禁止过滤、虚拟列表、树形叶子、光大字典禁止搜索、同名候选拒绝、省市级联、动态简历字段、
重复经历、日期范围扫描、网页回滚、批量保护、停止和复核。
自动化填写回归 48 项，另有弹出页登录、简历选择、关注岗位、填写方式和客服交互检查。
浏览器验收覆盖悬浮框真实鼠标拖动、关闭、重新打开与一键填写虚构表单。
另有本地真实 React 17 / Ant Design 4.24.16 浏览器验收页，
17 个场景涵盖学校编码、异步三级地区、中文年月日/月份/年份、光大公开代码的 onFocus 字典加载与 code[]/label[] 存储，
以及拒绝提交、路径不足、重名选项。13 个合法场景填写并复核通过，4 个应拒绝场景正确拒绝。
这些是本地复现，不能替代光大登录页面的实际保存结果验收。

电信本地真实 Angular/jQuery 控件验收 7 个场景（5 个合法场景填写且复核通过，2 个禁止/只读场景正确拒绝）。
信达公开原版 Phoenix React 组件验收 5 个场景：完整日期、月份、民族、学历、三级地区。
均检查到回显及组件选项编码，普通下拉/地区测试没有输入搜索词。
电信与信达在线登录页未完成真实账号保存验收，这些结果不代表线上所有字段均已成功保存。
国籍、出生地、家庭住址、意向单位、岗位类别及申请人承诺等缺少对应数据或有声明歧义的字段仍不猜测。

当前不支持自定义多选下拉、Ant Design 双面板日期范围的自动选择、
部分 readonly Element 日期选择器、跨域 iframe 内表单、封闭 Shadow DOM。
日期范围会分别扫描开始和结束，不能操作的控件显示失败并交给手动选择。
部分网页不在 DOM 显示内部保存状态，因此“复核通过”表示网页回显和可观察校验通过，
仍需用户核对最终保存结果。

接口日志只保留 URL、方法、状态码和返回顶层键，最多 100 条，
不记录请求头、token、完整个人资料或接口返回值。

## 本地开发验证

测试依赖仅用于开发，不打包进插件：

    NODE_PATH=<包含 jsdom22 的 node_modules> node scripts/test_autofill_extension.cjs

    NODE_PATH=<包含 jsdom22 的 node_modules> node scripts/test_extension_popup.cjs

本地视觉验收：启动下方 fixture 服务后打开 `/extension-popup-preview` 与
`/scripts/fixtures/extension-floating.html`。预览使用虚构数据，不请求真实账号接口，不打包进插件。

真实组件验收（临时依赖 React17、react-dom17、AntD4、moment）：

    XIAOMAI_FIXTURE_DEPS=<测试 node_modules> node scripts/serve_autofill_fixture.cjs

打开 http://127.0.0.1:18763/scripts/fixtures/autofill-antd.html，运行页面的 runCases()。
所有资料都是虚构测试数据，无提交请求。

电信控件验收页为 /scripts/fixtures/autofill-wintalent.html；信达为 /scripts/fixtures/autofill-phoenix.html，均运行 runCases()。
后两者依赖已下载的公开控件资源，测试目录分别为 deps 下的 telecom/、phoenix/；Phoenix 服务仅注册公开 vendor 模块，不启动招聘应用或读取真实表单。
